# Zellij 终端复用器

配置位置：`modules/home-manager/cli/tools/zellij.nix` + `zellij/config.kdl`（简化界面，无插件）。

Zellij 是模式化复用器：先按 `Ctrl` 组合键进入对应模式，再按单键执行动作；`Esc` / `Enter` 返回。

## 模式入口

| 按键 | 进入模式 |
| --- | --- |
| `Ctrl` + `p` | Pane 模式（面板） |
| `Ctrl` + `t` | Tab 模式（标签页） |
| `Ctrl` + `n` | Resize 模式（调整大小） |
| `Ctrl` + `s` | Scroll 模式（滚动） |
| `Ctrl` + `o` | Session 模式（会话） |
| `Ctrl` + `q` | 退出 Zellij |

## 面板 (Pane 模式 `Ctrl`+`p`)

| 按键 | 功能 |
|------|--------|
| `d` | 下方新建面板 |
| `r` | 右侧新建面板 |
| `n` | 新建面板（默认方向） |
| `x` | 关闭当前面板 |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 切换焦点 |
| `p` | 切换面板 |
| `;` | 聚焦上一个面板 |

## 标签页 (Tab 模式 `Ctrl`+`t`)

| 按键 | 功能 |
|------|--------|
| `n` | 新建标签页 |
| `x` | 关闭当前标签页 |
| `h` / `l` | 上一个 / 下一个标签页 |

## 滚动 (Scroll 模式 `Ctrl`+`s`)

| 按键 | 功能 |
|------|--------|
| `j` / `k` | 向下 / 向上滚动 |
| `Ctrl` + `c` | 滚到底部并退出 |

## 会话 (Session 模式 `Ctrl`+`o`)

| 按键 | 功能 |
|------|--------|
| `d` | 分离（detach）当前会话 |
| `s` | 切换会话 |

## 快速操作（normal 模式）

| 按键 | 功能 |
|------|--------|
| `Alt` + `h/j/k/l` | 快速切换面板焦点 |
| `Alt` + `n` | 快速新建面板 |
| `z`（pane 模式） | 最大化 / 还原面板 |

重新连接会话：`zellij attach <会话名>`（或直接运行 `zellij` 恢复上次会话）。
