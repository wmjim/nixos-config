# Helix 编辑器

配置位置：`modules/home-manager/cli/editors/helix.nix`（`config.toml` + `languages.toml`）。

Helix 是模态编辑器：`normal`（默认）→ 按 `i`/`a` 进入 `insert` → `Esc` 返回。

## 光标移动（normal 模式）

| 按键 | 功能 |
| --- | --- |
| `h` `j` `k` `l` | 左 / 下 / 上 / 右 |
| `w` `b` `e` | 词首前进 / 词首后退 / 词尾前进 |
| `f` + 字符 | 行内跳到该字符 |
| `g` `g` | 文件开头 |
| `G` | 文件结尾 |
| `%` | 匹配括号跳转 |
| `Ctrl` + `d` / `u` | 下翻半页 / 上翻半页 |

## 编辑

| 按键 | 功能 |
| --- | --- |
| `x` | 选择整个行 |
| `v` | 切换到选择模式 |
| `y` | 复制选中内容 |
| `p` | 粘贴 |
| `d` | 删除 |
| `c` | 修改（删除并进入插入模式） |
| `u` | 撤销 |
| `Ctrl` + `r` | 重做 |
| `C` | 列选择（多光标） |
| `space` + `/` | 注释 / 取消注释 |
| `space` + `x` | 代码操作（如导入补全） |

## 搜索与跳转

| 按键 | 功能 |
| --- | --- |
| `/` | 文件内搜索 |
| `space` + `f` `f` | 文件选择器（fuzzy 打开文件） |
| `space` + `g` `g` | 全局符号（跳转到定义） |
| `space` + `s` | 当前文件符号 |
| `g` `d` | 跳转到定义（LSP） |
| `g` `a` | 跳转到引用 |
| `space` + `r` | LSP 重命名 |

## LSP 与格式化

| 按键 | 功能 |
| --- | --- |
| `space` + `l` | LSP 菜单 |
| `space` + `d` | 打开诊断（错误列表） |
| `space` + `a` | 代码操作 |
| `space` + `f` | 格式化（当前语言） |
| `space` + `k` | 悬停文档 |

## 分屏

| 按键 | 功能 |
| --- | --- |
| `:vsplit` / `:hsplit` | 垂直 / 水平分屏 |
| `space` + `w` + `h/j/k/l` | 切换分屏焦点 |
| `space` + `w` + `q` | 关闭当前分屏 |

## 命令模式

| 按键 | 功能 |
| --- | --- |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:format` | 格式化 |
| `:sh <cmd>` | 执行 shell 命令 |

> 其他快捷键可用 `space` + `?`（打开按键速查）查看完整列表。
